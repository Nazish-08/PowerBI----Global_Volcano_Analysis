# 🌋 Global Volcano Analysis | Power BI

An interactive Power BI data analysis project focused on exploring and visualizing global volcano data.

The project uses Microsoft Power BI to transform volcano-related data into interactive dashboards, visualizations, and analytical insights.

---

## 📌 Project Overview

The **Global Volcano Analysis** project provides a visual analysis of volcano-related data across different geographic and analytical dimensions.

The dashboard is designed to make global volcano data easier to explore through:

- 🌍 Geographic analysis
- 🌋 Volcano classification
- 📊 Data visualization
- 🔎 Interactive filtering
- 📈 Comparative analysis
- 📌 KPI-based reporting
- 🗺️ Location-based visualization
- 📋 Structured data analysis

---

## 🎯 Project Objectives

The main objectives of this project were:

- Analyze global volcano data
- Understand the geographic distribution of volcanoes
- Identify patterns within the dataset
- Analyze volcano classifications
- Explore geographic and categorical relationships
- Create an interactive Power BI dashboard
- Use filters and slicers for data exploration
- Present complex data through clear visualizations
- Extract meaningful insights from the available dataset
